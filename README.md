# astrokod-figury

Приложение формирует персональный гороскоп для похудения по знаку зодиака.

## Заметки по разработке

### VK Mini Apps: публикация истории (`VKWebAppShowStoryBox`)

**Текущее решение (план Б):** текст полностью рисуется на canvas-фоне, история публикуется без стикеров. Проверено: такой payload открывает редактор истории даже на десктопе.

**Работающие элементы payload (проверено тестами):**
- `background_type: "image"` + `blob` (data URL строка, PNG) — открывает редактор истории;
- `action_type: "link"` + `action: "https://vk.com/app{id}"` (строка URL) — добавляет кнопку «Перейти в приложение» на опубликованной истории. В превью редактора кнопка не видна — проверять нужно на опубликованной истории.

**Известная проблема:** добавление любого стикера в `VKWebAppShowStoryBox` приводит к ошибкам валидации VK:
- `Missing required param "action_type"` (при `sticker_type: "native"`);
- `Missing required param "content_type"` (при `sticker_type: "renderable"`);
- `Missing required param "sticker"` (при структуре renderable из сниппета с `type`/`sticker_type`/`renderable`).

Пробовали разные комбинации `action_type`/`action` (включая `"none"`, `"link"` со строкой и объектом `{type, link}`/`{type, url}`), упрощение структуры стикера, убирание `rounded_rect`, renderable-структуру с `clickable_zone` и `renderable` — ошибка сохраняется. При этом payload **без стикеров** работает.

**Если в будущем захочется редактируемый текст на истории:** нужно разобраться с корректной схемой стикера в актуальной документации VK (`dev.vk.com/ru/bridge/overview` → `VKWebAppShowStoryBox`), в issues репозитория `VKCOM/vk-bridge` или подсмотреть payload в JS-бандле приложений, которые публикуют истории. Судя по ошибке `Missing required param "sticker"`, в renderable тоже ожидается вложенное поле `sticker` — найденный в интернете сниппет был неполным.

**Временное решение по посту на стену:** публикация на стену отключена — приложение ещё не получило право `wall`, VK отвечает ошибкой «Нет прав на пост». Вернуть после настройки прав или модерации.
